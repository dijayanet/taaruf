## 📖 Overview

**Ta'aruf Al-Mizan** is a premium Islamic matchmaking web application that facilitates the ta'aruf process through structured biodata submission. Built with simplicity and Islamic values at its core, the platform enables users to present their profile in a dignified, organized manner.

### 🎯 Purpose

- Provide a **Sharia-compliant** platform for marriage introduction
- Maintain **data privacy** and security
- Streamline the **biodata collection** process
- Uphold **Islamic etiquette** in matchmaking

---

## ✨ Features

### User-Facing
- ✅ **Multi-Step Form** (4 steps with progress bar)
- ✅ **Responsive Design** (Mobile-first approach)
- ✅ **Instant Validation** for each step
- ✅ **Loading States** during submission
- ✅ **Success/Error Feedback** with Islamic greetings
- ✅ **Privacy Notice** displayed prominently

### Admin-Facing
- ✅ **Google Sheets Integration** for data storage
- ✅ **Timestamp Tracking** for each submission
- ✅ **Structured Data Format** for easy analysis
